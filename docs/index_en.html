의미론적 하이브리드 검색 (RRF)

단순 키워드 FTS 검색과 문맥을 이해하는 Vector Embedding 검색을 Reciprocal Rank Fusion(RRF) 알고리즘으로 융합하고 LLM Cross-Encoder로 재순위화합니다.

  • SQLite FTS5 & Postgres pgvector
  • 자연어 질문 기반 실시간 탐색

Model Context Protocol (MCP)

Claude Code, Cursor 등 최신 AI 에이전트에 연동하여 메일 수집, 하이브리드 검색, 초안 작성 및 승인 발송 요청을 안전하게 수행합니다.

  • Stdio (로컬) & Streamable HTTP (:8480)
  • 5단계 MCP RBAC (read~admin)

IMAP IDLE 실시간 동기화

RFC 2177 IMAP IDLE 기술을 적용하여 새 메일 도착 시 푸시 알림 방식으로 즉시 수집하며, 백그라운드 스케줄러가 안정적인 동기화를 유지합니다.

  • POP3 / IMAP 멀티 프로토콜 지원
  • 오프라인/격리망 안전 수집 플래그

Keycloak OIDC SSO & 분산 확장

기업용 Keycloak OAuth2 / OpenID Connect SSO, S256 PKCE를 완벽 지원하며, Kubernetes 멀티 노드 배포 시 세션 무결성을 제공합니다.

  • Argon2id 패스워드 암호화

AI 발송 제어: 해시 기반 일회성 승인 토큰

AI 에이전트는 메일 작성 시 **오직 초안(`draft`)만 생성**하며, 실제 발송을 위해서는 페이로드 해시에 묶인 **일회성 승인 토큰(Approval Token)**을 사람이 직접 검토/승인해야 합니다. 내용 변경 시 기존 토큰은 즉시 파기됩니다.

Model Context Protocol

Claude Code & Cursor 연동 스니펫

표준 MCP 프로토콜을 통해 AI 개발 환경에서 수초 만에 메일 에이전트를 가동할 수 있습니다.

`~/.claude.json` 파일에 Postra Stdio MCP 실행 설정을 추가하세요. 

{
  "mcpServers": {
    "postra": {
      "command": "/usr/local/bin/postra",
      "args": ["mcp"]
    }
  }
}

`postra serve` 기동 시 HTTP Streamable MCP 엔드포인트가 `/mcp`로 노출됩니다. 

# Postra 통합 서버 기동 (Web UI + REST + MCP)
POSTRA_API_TOKEN="your-secure-mcp-token" ./postra serve

# Remote MCP Endpoint
Endpoint: http://127.0.0.1:8480/mcp
Header:   Authorization: Bearer your-secure-mcp-token

PostgreSQL + pgvector 데이터베이스와 함께 Postra 컨테이너를 가동합니다. 

version: '3.8'
services:
  postra:
    image: postra/postra:latest
    ports:
      - "8480:8480"
    environment:
      - POSTRA_STORAGE_DRIVER=postgres
      - POSTRA_POSTGRES_DSN=postgres://postra:secret@db:5432/postra?sslmode=disable
      - POSTRA_KEK=your-super-secret-kek-key-32bytes!
    depends_on:
      - db
  db:
    image: pgvector/pgvector:pg16
    environment:
      POSTGRES_USER: postra
      POSTGRES_PASSWORD: secret
      POSTGRES_DB: postra

AEO & Knowledge Base

자주 묻는 질문 (FAQ & AEO)

AI 검색엔진(Perplexity, SearchGPT, ChatGPT, Claude) 및 검색엔진이 최적으로 구조화 파싱할 수 있도록 정리된 핵심 Q&A입니다.

Postra란 무엇인가요?

Postra는 Go 언어로 작성된 개인 및 기업 사내 구축형 메일 AI & Model Context Protocol (MCP) 플랫폼입니다. POP3/IMAP/SMTP 계정을 연결하여 안전하게 수집, 하이브리드 검색, 트리아지 분석, AI 작성 및 승인 발송을 제공합니다.

Postra는 메일 비밀번호와 데이터를 어떻게 암호화하나요?

Zero-Trust 봉투 암호화(Envelope Encryption: KEK→DEK, AES-256-GCM) 기술을 사용합니다. 메일 비밀번호는 SecretHandle로 캡슐화되어 AI 컨텍스트로 절대 유출되지 않으며 본문과 첨부파일은 at-rest 상태로 암호화 저장됩니다.

AI 메일 발송 시 무단 발송 위험은 없나요?

없습니다. Postra에서 AI는 오직 초안(Draft)만 작성하며, 실제 메일 발송은 수신자·제목·본문 해시에 바인딩된 일회성 승인 토큰(Approval Token)을 사람이 직접 승인해야 합니다. 내용 변경 시 토큰은 즉시 무효화됩니다.

의미론적 하이브리드 검색은 어떻게 동작하나요?

SQLite FTS5 키워드 검색과 PostgreSQL pgvector 문맥 의미 검색을 RRF(Reciprocal Rank Fusion) 파이프라인으로 융합하고, 선택적으로 LLM Cross-Encoder 재순위화(Reranking)를 거쳐 정확한 자연어 검색 결과를 제공합니다.

Deployment Guide

1분 이내에 서버 구축 및 시작하기

Go 바이너리 빌드부터 비밀번호 암호화 등록, 계정 연결 및 서빙까지 한 눈에 확인하세요.

# 1. Postra 빌드 및 초기화
go build -o postra ./cmd/postra
./postra init                          # ~/.postra/config.json 생성

# 2. 메일 비밀번호를 안전한 TTY 경로로 등록 (SecretHandle 획득)
./postra secret set --type mail_password --label "내 메일 계정"

# 3. POP3 / IMAP / SMTP 계정 등록 (비밀번호 원문 전달 금지)
./postra account add --name "Work" --email me@company.local \
  --pop3-host pop.company.local --pop3-security tls --pop3-user me \
  --pop3-secret-ref sec_xxx \
  --smtp-host smtp.company.local --smtp-security tls --smtp-user me --smtp-secret-ref sec_xxx

# 4. 수집 진단 및 테스트
./postra account test --id acc_xxx
./postra sync --account acc_xxx --wait

# 5. 통합 서비스 기동 (Web UI: http://127.0.0.1:8480/ui)
./postra serve
