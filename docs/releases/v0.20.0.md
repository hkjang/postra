# Postra v0.20.0 — Web/MCP Architecture Convergence

Postra를 **Self-hosted AI Mail & Work Agent Platform**으로 통합하는 기능 릴리즈입니다. React 웹 사용자와 MCP Agent가 같은 메일·업무·설정·렌더링·승인 서비스를 사용합니다. 운영 시 Node 서버나 외부 CDN 없이 Go 단일 실행 파일과 폐쇄망 배포를 유지합니다.

## 공식 UI와 인증 전환

- `/`는 `/app/`으로 이동하고 `/app`은 trailing slash로 정규화합니다. React에서 로그인·최초 설정·메일·스레드·검색·작성·발송함·업무·액션·규칙·계정·AI·관리 화면을 제공합니다.
- 기존 `internal/transport/webui`와 Go HTML 템플릿·정적 파일을 제거했습니다. `/ui/login`, `/ui/admin/*`, `/ui/static/*`는 더 이상 지원하지 않습니다.
- 인증은 `/auth/session`, `/auth/login`, `/auth/setup`, `/auth/logout`, `/auth/oidc/start`, `/auth/oidc/callback`으로 분리했습니다. SSO 실패 사유의 서명된 일회용 쿠키, PKCE/state/nonce, 깊은 링크, 자동 로그인 반복 방지, Origin/CSRF 검증을 유지합니다.
- 전환을 위해 **이번 버전만** `/ui[/]`, `/ui/messages/{id}`, 기존 `/ui/auth/oidc/callback`에 좁은 이전용 리다이렉트를 제공합니다. 일반적인 `/ui/*` 프록시나 레거시 화면은 없습니다. 이 shim은 v1에서 제거할 예정입니다.

## 설정을 웹 운영 콘솔로

- 관리자 콘솔을 일반·인증/SSO·메일·AI·검색/임베딩·MCP·발송·첨부·동기화·보안·알림·저장소·시스템·사용자·감사의 15개 카테고리로 정리했습니다. 이름·설정 키·환경변수 이름으로 검색할 수 있습니다.
- 기본값 → 파일/환경 초기값 → 관리자 → 사용자 → 계정 순으로 적용하며 관리자 강제 정책이 우선합니다. 출처, 현재 실행값, 재시작 대기, 저장 전 변경 내역을 확인할 수 있습니다.
- AI Endpoint/모델/토큰/timeout/context/temperature, 작업별 모델, 외부 호출·PII 마스킹, 발송 제한·첨부 정책·MCP 권한을 같은 설정 서비스에서 조회합니다. 작업 루프는 최대 5초마다 새 주기·동시성·활성 상태를 확인합니다.
- 저장소 경로·DB 선택·KEK/암호화 같은 배포 항목은 조회 전용입니다. 리스너·MCP endpoint/session timeout 등 재시작 항목은 명확히 구분합니다. **모든 발송의 명시적 승인은 해제할 수 없는 고정 정책**입니다.
- 비밀번호·API Key·게이트웨이 헤더는 암호화 저장하고 등록 여부만 표시합니다. 키별 변경 감사와 미저장 변경 보호를 추가했습니다. AI/Embedding 후보 설정 시험은 저장 없이 수행하며, OIDC discovery·현재 DB·메일 계정 진단도 제공합니다.
- 관리자 설정의 DB 원자적 비교·저장으로 동시 수정 충돌을 감지하고, COMMIT 응답 유실 시 실제 사용 중인 키를 폐기하지 않습니다. 서버 오류를 담는 DTO·감사·장애·추적에서는 원문 대신 안전한 안내를 사용합니다. 알려진 과거 진단도 원본 DB 변경 없이 조회 시 보호합니다.
- 개인 화면에서 theme/density/reader/snippet/AI panel, 기본 계정·검색·알림·날짜/locale, 작성 형식·톤·길이·언어를 관리합니다. 계정별 수집 주기·스타일·템플릿과 여러 서명도 선택할 수 있습니다.

## 웹과 MCP가 공유하는 메일 렌더러

- `text`, `markdown`, `html`, `auto` 입력과 `clean`, `formal`, `concise`, `notice`, `report`, `newsletter`, `plain` 템플릿을 지원합니다. 기본 렌더링은 결정적 로컬 처리이며 `smart_format=true`를 요청할 때만 AI를 호출합니다.
- 허용 목록 HTML sanitizing, 인라인 CSS, 동일한 canonical 본문 기반 plain 대안·DLP·미리보기·승인 해시를 적용합니다. HTML은 `multipart/alternative`, CID 이미지는 `related`, 일반 첨부는 바깥 `mixed`로 발송합니다.
- 파일 drag/drop·붙여넣기·이미지 붙여넣기, 첨부 검사·불변 버전·소유권·해시 검증, 선택 문장 AI 재작성 후 명시적 적용, 구조화 서명과 새 메일/첫 답장/후속 답장 서명 정책을 추가했습니다.
- 외부 이미지는 수신·발송 정책을 분리합니다. 기본 차단, 수신 시 한 번 보기/발신자·도메인 허용, 발송 allow/proxy/block을 제공하며 관리자 정책이 우선합니다. 로컬 미리보기는 외부 이미지를 자동 로드하지 않습니다.
- 초안이나 첨부를 변경하면 기존 승인은 무효입니다. 중복 요청과 SMTP 최종 응답 유실은 기존 멱등성·불확실 상태로 처리하며 자동 중복 발송하지 않습니다.

## MCP·REST·업무 경험

- 모든 MCP 도구와 별칭에 실제 DTO 기반 출력 스키마와 입력 스키마, 부작용·승인·scope 메타데이터를 제공합니다. discovery, `postra://` 리소스, 프롬프트, 최근 호출·감사·지표, 동일 Job 상태/진행률을 확장했습니다.
- 클라이언트 키별 읽기·검색·AI·초안·발송·삭제·업무·관리 scope를 저장합니다. 열린 세션에도 키 폐기·권한 축소를 적용하고 다른 키의 세션 ID 재사용을 차단합니다. MCP 키로 REST를 호출해도 같은 정책을 적용합니다.
- `/api/v1/`을 정식 경로로 제공하고 `/api/`는 호환 alias로 유지합니다. 공통 공개 오류/trace 계약과 핵심 DTO → JSON Schema/OpenAPI/TypeScript 생성·CI drift 검사를 추가했습니다.
- Ask Postra는 메일·업무·액션·기간/시간대 조건과 실제 근거 링크를 함께 제공합니다. Work 5단계, SLA·메모·담당자·액션, 기한별 Action Center, Smart Inbox, 키보드·명령 팔레트·Copy MCP Context, 개인 SSE 알림을 통합했습니다.
- 관리자도 자신의 메일만 읽을 수 있습니다. 기존 이메일 기반 SSO 메일 프로비저닝, 관리자 지정 공통 IMAP 비밀번호와 무인증 SMTP 정책, 이전 소유자 메일 정리 기능을 유지합니다.

## 업그레이드 전 확인

1. **DB·SecretStore·ObjectStore·KEK를 함께 백업**하고 기존 볼륨과 키를 유지하세요. SQLite/PostgreSQL에는 읽음 상태, MCP scope, 초안 첨부 버전의 추가 컬럼이 자동 반영됩니다. 읽음 기록이 없던 기존 메일은 안읽음으로 시작합니다. 다운그레이드는 업그레이드 전 백업으로 복구하는 방식으로 계획하세요.
2. Keycloak에 `https://<Postra>/auth/oidc/callback`을 먼저 추가한 후 관리자 OIDC redirect URL을 바꾸고 실제 로그인·자동 로그인·로그아웃을 확인하세요. 기존 `/ui/auth/oidc/callback` 저장값을 임의로 덮어쓰지 않으며 전환 중 token exchange는 등록된 기존 URI를 유지합니다.
3. 새 MCP 키는 기본 읽기·검색만 허용하며 명시적 `[]`는 데이터 도구 접근을 차단합니다. 기존 scope 없는 키는 `legacy_scopes`로 표시하고 기존 비관리 권한을 호환합니다. 관리/삭제는 기본 조직 정책에서도 차단하므로 필요한 클라이언트별로 검토하세요.
4. 저장한 관리자 값이 환경변수보다 우선합니다. 기존 AI 추가 헤더·Milvus 토큰의 평문 저장값은 암호화 Secret 참조로 이관합니다. 암호화 저장소를 읽지 못하면 초기값으로 조용히 우회하지 않습니다.
5. 외부 이미지 기본 차단과 HTML 정책을 확인하세요. 정책 강화로 기존 승인된 HTML이 허용되지 않으면 초안을 다시 렌더링하고 검토·승인해야 합니다. 사내 SMTP relay에서 text/rich/한글 첨부/CID 샘플을 실제 수신 클라이언트로 확인하세요.

## 검증과 명시적 범위

Go unit/race/vet, React unit/typecheck, 실제 Chromium의 로컬 로그인·setup·서명된 mock OIDC·사용자 격리·설정 잠금·외부 이미지·모바일·발송 흐름, MCP 검색→요약→답장→미리보기→승인→발송→상태 계약, HTML/MIME golden 및 보안 회귀를 검증했습니다. 실제 로컬 TCP SMTP와 별도 PostgreSQL/pgvector 테스트 인스턴스로 무인증 발송·불확실 응답·멱등성·암호화 재시작·저장 계약을 확인했습니다. 운영 메일·외부 AI·실제 사용자 데이터는 이 검증에 사용하지 않았습니다.

이 버전은 v1.0 인증 선언이 아닙니다. Markdown은 메일용 부분 문법이며, OpenAPI 생성은 설정·Ask·렌더링·초안·미리보기·첨부·서명의 핵심 계약 범위입니다. UI 문구는 한국어 중심이고 locale은 날짜/HTML 언어에 적용됩니다. Context Length는 보수적 문자 예산이지 모델 tokenizer가 아닙니다. 바이너리 첨부의 PDF/Office/OCR DLP, 모든 메일 클라이언트의 동일한 픽셀 렌더링, 실제 사내 릴레이 도달성은 보증하지 않습니다. 기존 선택적 OpenTelemetry OTLP/HTTP exporter는 유지합니다. 사용자 문체 학습·세밀한 분산 추적 확장·고급 외부 자동화는 후속 확장 대상이며 동작하지 않는 토글로 노출하지 않습니다.
