# Postra v0.21.1 — 글자 크기 통일과 답장 원문 확인

워크스페이스의 가독성과 답장 작성 흐름을 개선했습니다. 화면별로 달랐던 글자 크기를 공통 기준으로 정리하고, 사용자별 큰 글자 설정과 답장·전달 원문 확인 패널을 추가했습니다.

## 일관된 글자 크기와 개인 설정

- 본문·입력·버튼 15px, 보조 설명 13px, 배지·단축키 12px, 카드 제목 16px, 섹션 제목 18px, 페이지 제목 24px를 기준으로 통일했습니다. 실제 크기는 rem 기반이므로 브라우저 기본 글꼴과 확대 설정을 존중합니다.
- **개인 설정 → 화면 글자 크기**에서 기본 또는 크게(112.5%)를 선택합니다. 저장 즉시 반영되고 사용자별로 서버에 저장되어 재접속·재시작에도 유지됩니다.
- 관리자는 일반 설정에서 조직 기본값이나 강제 정책을 지정할 수 있습니다. 밀도 설정과 글자 크기는 독립적이며 값 출처·변경 이력은 기존 설정 시스템을 사용합니다.
- 설정 설명과 정책 안내의 글자색을 수정했습니다. 받은 HTML 메일과 작성한 메일 본문의 사용자 지정 서식은 변경하지 않습니다.

## 답장·전달 원문 확인

- 답장·전체 답장·전달 초안에서 원문 패널을 펼쳐 발신자·수신자·시각·제목·본문을 확인합니다. 원본 메일을 새 탭으로 여는 링크도 제공합니다.
- 명시적으로 펼칠 때만 본인에게 조회 권한이 있는 원문을 가져옵니다. 패널 조회는 읽음 상태·초안 본문·발송 승인 상태를 변경하지 않고 AI 호출이나 메일 발송도 하지 않습니다.
- 텍스트 본문을 우선 표시하고 HTML 전용 원문은 외부 이미지가 차단된 격리 프레임으로 표시합니다. HTML 링크나 첨부파일은 원본 메일을 새 탭으로 열어 확인합니다.
- 원문 삭제·권한·네트워크 오류가 발생해도 작성 중인 내용은 보존하며 패널에서 재시도할 수 있습니다. 다른 초안으로 이동하면 이전 원문 조회를 취소하고 패널을 접힌 상태로 초기화합니다.

## 모바일 가독성

- 좁은 화면에서도 글자 크기를 줄이지 않고 툴바·버튼·미리보기 정보를 줄바꿈합니다.
- 540px 이하 작성 화면에서는 라벨을 입력란 위에 배치해 주소와 제목 입력 공간을 확보합니다.
- 모바일 업무함의 상태·정렬 필터를 각각 전체 너비로 표시해 선택값 대신 화살표만 보이던 문제를 수정했습니다.

## 업그레이드 및 운영 안내

v0.21.0에서 추가 DB 마이그레이션이나 새 필수 환경변수는 없습니다. 데이터·SecretStore·ObjectStore·KEK를 백업하고 유지한 상태에서 실행 파일 또는 컨테이너 이미지를 교체한 뒤 서비스를 다시 시작하세요. 기존 사용자에게는 기본 글자 크기가 적용됩니다.

기존 SSO·메일 프로비저닝·사용자별 메일 격리·발송 승인·멱등 발송을 유지합니다. Go 단일 바이너리에 React 자산·글꼴을 포함하므로 폐쇄망 운영에 Node 서버나 외부 CDN은 필요하지 않습니다. v0.19.x 이하에서 올리는 경우 [v0.20.0 이전 안내](https://github.com/hkjang/postra/blob/v0.21.1/docs/releases/v0.20.0.md)의 Keycloak 콜백·UI·권한 변경도 먼저 확인하세요.

자세한 사용법: [개인·운영 설정](https://github.com/hkjang/postra/blob/v0.21.1/docs/SETTINGS.md), [React 워크스페이스](https://github.com/hkjang/postra/blob/v0.21.1/docs/REACT_WORKSPACE.md).

## 검증

- Go race 테스트·Go vet·canonical API 계약 검사
- React 단위·회귀 테스트, TypeScript 검사, 배포 자산 재빌드
- 실제 브라우저 로그인·OIDC·설정·사용자 격리·승인 발송 E2E 3종
- 큰 글자 설정 저장·즉시 반영·재조회·재시작·관리자 정책 검증
- 6개 화면의 데스크톱·390px·320px 가독성 및 가로 넘침 검사
- 원문 패널의 지연 조회·외부 이미지 차단·오류 시 작성 내용 보존·초안 전환 검사

테스트 데이터와 모의 AI·메일·OIDC 서비스를 사용합니다. 운영 AI 호출·실제 메일 발송·운영 데이터 변경은 수행하지 않습니다.
