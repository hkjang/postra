# Postra v0.21.0 — 메일 후속 업무와 워크스페이스 UX 개선

메일을 읽은 뒤 다시 확인하거나 할 일로 연결하는 과정을 줄이는 기능 릴리즈입니다. 메일별 다시 보기 예약, 검색·선택 기반 액션 생성, 기한 중심 업무함을 추가하고 AI 진단·설정 편집 보호도 강화했습니다.

## 메일별 다시 보기 예약

- 메일 상세에서 예약 시각을 확인하고 설정·변경·해제합니다. 1시간 뒤, 내일 오전 9시, 다음 월요일, 3일·일주일 뒤 또는 날짜·시각 직접 지정을 지원합니다.
- 받은메일 일괄 작업에서도 직접 날짜를 지정합니다. 과거 시각, 잘못된 날짜, 현지 서머타임 전환으로 존재하지 않는 시각을 거부합니다.
- 예약 시각까지 받은메일에서 숨기고 이후 다시 표시합니다. 열린 받은메일·다시 알림 목록의 해당 GET 조회를 60초 주기로 갱신하며 백그라운드 탭과 비용이 생길 수 있는 의미·통합 AI 검색은 자동 갱신하지 않습니다.
- 이 기능은 Postra의 로컬 메일 상태입니다. 푸시 알림·메일 발송·외부 일정 등록은 하지 않으며 보관된 메일은 보관 해제도 필요합니다. 숨겨진 탭에서는 다시 활성화하거나 목록을 새로고침해야 할 수 있습니다.

## 원본 메일 선택과 액션 센터

- 메일 상세의 **이 메일에서 액션 만들기**로 원본을 연결하고 제목을 기본값으로 채웁니다. 액션 센터에서는 최근 메일이나 검색 결과에서 선택하므로 메일 ID를 복사할 필요가 없습니다.
- 원본 선택 목록은 내 소유 메일만 조회하며, 선택만으로 읽음 처리·AI 호출·액션 생성은 하지 않습니다. 직접 수정한 제목은 원본을 바꾸거나 늦은 응답이 도착해도 유지합니다.
- 명시적으로 저장할 때만 검토 대기 액션을 생성합니다. 액션의 기한·담당자는 메일 업무함의 SLA·담당자와 별도이며 외부 업무 시스템에 자동 등록하지 않습니다.
- 제목·상세 내용·담당자 검색을 상태·기한 필터와 조합하고 필터를 한 번에 초기화합니다. 선택한 상태의 최근 최대 200건 안에서 조회한다는 범위도 표시합니다.
- 작성 중 이동·로그아웃 확인, 저장 중 중복 요청 차단, 저장 결과가 불확실할 때 목록부터 확인하는 안내를 추가했습니다. 상태 변경과 내보내기 버튼의 동시 요청도 막습니다.

## 기한 중심 업무함과 모바일 UI

- 전체·지연·오늘·예정·기한 없음 필터와 건수를 제공합니다. 지연은 현재 시각 이전, 오늘은 현지 날짜 안의 남은 기한이며 완료 업무는 지연 건수에 포함하지 않습니다.
- 기한 빠른순 정렬은 각 진행 상태 안에서 급한 업무를 먼저 표시합니다. 기한 없는 업무는 뒤로, 완료 업무는 최근 변경순으로 유지합니다.
- 건수·정렬은 현재 담당자·상태 조건으로 불러온 최근 변경 최대 200건에 적용됩니다. 조직 전체 통계나 전체 보존 데이터 집계가 아닙니다.
- 좁은 화면에서는 업무 열을 세로로 배치하고, 기한·상태 필터 적용 시 빈 열을 숨깁니다. 버튼 선택 상태·키보드 조작·빈 결과 안내와 액션 입력 화면도 개선했습니다.

## AI 진단 및 설정 편집 보호

- 모델 목록 조회에서 미지원 경로, 한도 필드 미제공, 인증·권한·요청 제한·시간 초과·네트워크·응답 형식 오류를 구분합니다. 메타데이터 조회 실패와 실제 Chat·Embedding 연결 성공 여부를 별도로 안내합니다.
- AI 인증 실패는 Postra 로그인 만료로 처리하지 않습니다. 요청 제한과 사용 할당량·크레딧·조직/프로젝트 한도 초과를 구분하고, 오류에 서버 원문·URL·인증정보를 노출하지 않습니다.
- 인증·권한·사용 제한·네트워크 실패 및 시간 초과(HTTP 408/504 포함) 후 불필요한 기본 모델 자동 재호출을 차단합니다. v0.20.2의 명확한 생성 전 토큰 호환 오류 조정과 비타임아웃 5xx의 기존 기본 모델 대체는 유지합니다.
- 관리자 설정 검색을 지우거나 백그라운드 조회가 실패해도 입력값을 보존합니다. 저장·로그아웃 중 새 편집과 중복 저장을 막고 로그아웃 실패 시 편집 상태를 복구합니다.
- 비밀값 저장 실패 시 재입력을 안내하며 빈 재요청을 저장 성공으로 표시하지 않습니다. 잘못된 작업별 모델 JSON은 원문을 유지하고 간단 편집으로 덮어쓰지 않습니다.

## 업그레이드 및 운영 안내

v0.20.2에서 추가 DB 마이그레이션이나 새 필수 환경변수는 없습니다. 데이터·SecretStore·ObjectStore·KEK를 백업하고 유지한 상태에서 실행 파일 또는 컨테이너 이미지를 교체한 뒤 서비스를 다시 시작하세요. 기존 SSO·프로비저닝·사용자별 메일 격리·발송 승인·멱등 발송을 유지합니다.

Go 단일 바이너리와 폐쇄망 배포를 계속 지원합니다. React 자산·글꼴은 실행 파일에 포함되며 런타임 Node 서버나 외부 CDN은 필요하지 않습니다. v0.19.x 이하에서 올리는 경우 [v0.20.0 이전 안내](https://github.com/hkjang/postra/blob/v0.21.0/docs/releases/v0.20.0.md)의 Keycloak 콜백·UI·권한 변경도 먼저 확인하세요.

자세한 사용법: [업무·액션](https://github.com/hkjang/postra/blob/v0.21.0/docs/WORK_ACTIONS.md), [운영 설정](https://github.com/hkjang/postra/blob/v0.21.0/docs/SETTINGS.md), [React 워크스페이스](https://github.com/hkjang/postra/blob/v0.21.0/docs/REACT_WORKSPACE.md).

## 검증

- 전체 Go race 테스트, Go vet, canonical API 계약 검사
- React 전체 단위 테스트, 최종 변경분 회귀 테스트, TypeScript 검사와 배포 자산 재빌드
- 실제 Chromium 로그인·OIDC·설정·메일·AI·승인 발송 E2E 및 새 다시 보기·액션·업무 필터 흐름
- 모바일 가로 넘침 검사, 사용자별 원본 메일 격리, 날짜·서머타임 경계, 잘못된 응답·중복 클릭·입력 보존 검사

검증은 테스트 데이터와 모의 AI·메일·OIDC 서비스를 사용합니다. 운영 AI 호출·실제 메일 발송·운영 데이터 변경은 수행하지 않습니다.
