# Postra v0.19.0 — React AI 업무 워크스페이스와 HTML 메일

기존 Go 백엔드·계정·SSO를 그대로 사용하는 React 워크스페이스를 `/app/`에 추가했습니다. 메일 탐색부터 AI 분석·업무 처리·서식 메일 발송까지 하나의 화면 흐름으로 연결합니다. 기존 `/ui/`는 호환 화면으로 유지합니다.

## 새 워크스페이스

- React 19·TypeScript·Vite 기반 UI와 로컬 번들 글꼴·아이콘을 Go 단일 실행 파일에 포함합니다. 오프라인 운영에 Node 서버나 CDN은 필요하지 않습니다.
- 왼쪽 탐색·가상 스크롤 메일 목록·본문·오른쪽 AI Insight를 연결한 분할 화면을 제공합니다. 밝은/어두운 테마, 목록 밀도, 모바일 메뉴를 지원합니다.
- 키워드·의미·통합 검색과 `Ctrl+K` / `⌘K` 명령 검색, 중요·첨부·날짜·계정·폴더 필터를 제공합니다.
- AI 요약·중요도 분석·실행 항목·스마트 답장을 하나의 패널에서 요청할 수 있습니다. Ask Postra와 기간별 브리핑도 기존 API를 사용합니다.
- 내 업무, 팀 업무함의 3단계 보드, 담당자·처리기한·내부 메모, 액션 카드 검토·승인·완료·JSON 내보내기를 지원합니다.
- 본인 메일 계정 연결·설정·동기화·진단, 자동화 규칙, 발송 기록과 진행 중인 작업 알림을 추가했습니다.
- 관리자 화면에서 사용자, 대상 없는 기본 SSO 메일 프로비저닝, AI·보안·시스템 정책, 감사·장애, 이전 메일 데이터 정리를 관리할 수 있습니다. IMAP 공유 비밀번호와 SMTP 무인증 등 기존 설정을 유지합니다.

## 인증과 개인정보

- 기존 로컬 로그인·Keycloak OIDC 세션을 재사용합니다. 쿠키 인증 API 변경에는 세션에 연결된 CSRF 토큰과 동일 출처 검사를 적용하며, 기존 Bearer API 클라이언트는 유지합니다.
- 관리자가 활성화한 SSO 자동 로그인은 `/app/` 첫 진입에도 적용됩니다. 기존 `prompt=none` 흐름과 탭당 시도 제한을 재사용하고, 명시적인 로그아웃 후에는 자동 재로그인을 막습니다.
- 관리자도 본인 소유의 메일만 조회합니다. 사용자별 캐시를 분리하고 다른 탭에서 로그인 계정이 바뀌어도 이전 사용자 데이터가 재사용되지 않도록 했습니다.
- 메일 HTML과 발송 미리보기는 격리된 iframe에서 표시합니다. API 키·메일 비밀번호는 조회하지 않으며, 브라우저 오류에 요청 본문이나 비밀값을 출력하지 않습니다.
- 일시적인 서버 연결 실패에는 작성 중인 내용을 유지하고 재연결을 안내합니다. 실제 인증 만료·로그아웃·사용자 전환이 확인되면 이전 사용자의 화면과 캐시를 제거합니다.
- 프록시에서는 공개 Host를 보존하거나 전달 헤더를 신뢰할 수 있는 값으로 덮어써야 합니다. 자세한 운영 조건은 [워크스페이스 가이드](https://github.com/hkjang/postra/blob/v0.19.0/docs/REACT_WORKSPACE.md)를 확인하세요.

## HTML 서식 메일

- 새 메일과 초안 수정에 서식 편집기를 추가했습니다. 굵게·기울임·밑줄·글자색·제목·목록·정렬·링크를 사용할 수 있습니다. React 작성 화면은 TipTap 편집기로 표·글꼴도 지원합니다.
- 작성한 본문을 유지하면서 적용할 수 있는 **편지 / 공지 / 업무 공유** 디자인과 **HTML 직접 입력 / 일반 텍스트** 모드를 제공합니다.
- 기존 `text/plain` 전용 SMTP 생성을 개선했습니다. 서식 메일은 UTF-8 `multipart/alternative`로 일반 텍스트와 HTML을 함께 보내며, HTML을 지원하지 않는 수신 환경도 지원합니다.
- 발송 승인 화면에 격리된 HTML 미리보기를 추가했습니다. HTML 변경도 기존 승인 토큰을 무효화하며, 일반 텍스트로 수정하거나 AI로 다시 쓰면 이전 HTML이 남아 발송되지 않습니다.
- HTML은 안전한 요소와 인라인 서식만 남깁니다. 스크립트·폼·외부 이미지·위험한 URL을 제거하고 HTML 내용·링크 속성·외부 숨은참조까지 발송 보안 정책을 검사합니다.
- REST API 및 MCP의 초안 입력에 `body_html`을 지원합니다. 서버에서 정리한 HTML을 기준으로 일반 텍스트를 자동 생성합니다.
- 편집기 파일은 실행 파일에 포함됩니다. 외부 CDN이나 추가 서비스 없이 오프라인망에서 사용할 수 있으며, 기존 SMTP 무인증 설정도 그대로 동작합니다.

## 사용 방법

1. `/app/`에서 기존 회사 계정이나 SSO로 로그인합니다. 기존 UI의 **새 워크스페이스** 링크로도 이동할 수 있습니다.
2. **새 메일 작성**에서 수신자와 제목을 입력하고 서식 또는 디자인을 적용합니다.
3. **초안 저장**으로 저장합니다. 자동 저장 방식은 아니며, 미저장 내용이 있는 채로 이동할 때 확인합니다.
4. **미리보기 · 발송 → 내용 확인 · 승인 → 승인한 메일 발송** 순서로 발송합니다. 결과가 불확실하면 중복 전송하지 않고 발송 기록을 확인하도록 안내합니다.

기존 `/ui/`에서도 서식 편집기를 사용할 수 있습니다. 기존 화면에서는 **초안 만들기 / 변경 저장 → 발송 미리보기·승인 → 이 내용으로 승인 요청 → 발송 확정** 순서입니다.

기본적인 HTML과 안전한 인라인 스타일을 지원하며 외부 이미지·스크립트는 지원하지 않습니다. 실제 글꼴·여백 등은 수신 메일 프로그램에 따라 달라질 수 있습니다. AI 재작성 결과는 일반 텍스트이며 이후 서식을 다시 적용할 수 있습니다.

## 단계적 전환 범위

이번 릴리즈는 기존 API 범위에서 UI 계층을 현대화한 단계적 전환입니다. React 때문에 application/domain/storage 계층에 새 업무 모델을 추가하지 않았습니다. HTML 발송에 필요한 초안·MIME 처리는 별도로 개선했습니다.

- **초안 목록**: 현재 브라우저 세션에서 작업한 초안과 ID로 기존 초안 열기를 제공합니다. 새로고침 시 최근 목록은 초기화되지만 저장된 초안은 삭제되지 않습니다. 전체 서버 초안함에는 별도 목록 API가 필요합니다.
- **안읽음·발송 첨부**: 기존 모델/API에 없는 안읽음 상태와 작성 첨부 업로드는 이번 릴리즈에 포함하지 않습니다. 수신 첨부 다운로드는 지원합니다.
- **업무 상태**: 서버의 처리 전·진행 중·완료 상태를 사용합니다. 액션 JSON 내보내기는 외부 일정 서비스에 자동 등록하는 기능이 아닙니다.
- **고급 운영 설정**: 고급 방문 추적·CSP 출처 관리 등은 `/ui/admin/settings`에서 계속 사용할 수 있습니다. `/ui` 제거는 별도 전환 검증 후 진행합니다.

## 기존 릴리즈와의 호환

v0.18.7의 OIDC `prompt=none` 자동 로그인·안전한 리다이렉트, 실행 파일/이미지의 커밋·빌드 시각·OCI 라벨을 유지합니다. SSO 로그인과 메일 프로비저닝은 기존 설정을 재사용합니다.

## 검증

- 전체 Go race 테스트, `go vet`, `go build`.
- 프런트엔드 TypeScript·컴포넌트 회귀 테스트, 프로덕션 의존성 감사, Go 보안 검사.
- HTML 저장·재조회·수정·승인 무효화, MIME 양쪽 본문 디코딩, 한글·Unicode, 일반 텍스트 호환, DLP·숨은참조·무인증 SMTP 회귀 테스트.
- 실제 Chrome에서 서식·색상·링크·목록·디자인·HTML 입력·저장·미리보기·승인·발송, 일반 텍스트 전환, 모바일 레이아웃 및 외부 요청 없는 편집기 동작 확인. 발송 테스트는 가짜 SMTP로 수행하며 실제 사용자 메일은 전송하지 않았습니다.
- 실제 Go 인증·DB·API와 브라우저를 연결해 로그인·CSRF·메일 소유권·두 탭 사용자 전환·AI·업무·액션·서식 메일 발송·로그아웃을 확인했습니다. AI와 SMTP는 테스트 대역을 사용했습니다.

## 배포

기존 데이터베이스 스키마 변경이나 새 환경변수는 없습니다. 기존 볼륨·DB·Secret 설정을 유지한 채 바이너리 또는 이미지를 교체하세요.

- `postra-0.19.0-linux-amd64`: 정적 실행 파일
- `postra-0.19.0-linux-amd64-image.tar.gz`: 오프라인 `docker load`용 이미지 (`postra:0.19.0`)
- `postra-0.19.0-sbom.cdx.json`: CycloneDX SBOM
- `postra-0.19.0-frontend-sbom.cdx.json`: 프런트엔드 CycloneDX SBOM
- `SHA256SUMS.txt`: 배포 파일 무결성 검증

프런트엔드 소스 변경 시 `make frontend`로 빌드한 자산도 함께 커밋합니다. CI·릴리즈는 잠금 파일로 재빌드한 자산이 커밋과 일치하는지 확인합니다. 번들 라이선스는 `/app/THIRD_PARTY_NOTICES.txt`에 포함되어 있습니다.
