# Postra v0.20.1 — Workspace 안정성 및 메일 링크 개선

v0.20.0 배포 후 액션 센터와 메일 본문 링크에서 발생한 문제를 수정하고, 유사한 빈 응답·세션 만료 오류에 대한 방어를 강화한 패치 릴리즈입니다.

## 액션 센터와 목록 화면 안정성

- 액션 카드가 없을 때 REST/MCP 목록 응답이 `null` 대신 빈 배열 `[]`을 반환하도록 공통 application 계층을 보강했습니다. 계정·메일·초안·규칙·검색 등 관련 목록에도 같은 빈 배열 처리를 적용합니다.
- React에서 목록과 메일·AI 응답을 검증합니다. 지원하는 빈 응답은 빈 상태로 표시하고, 잘못된 JSON 구조나 HTML 프록시 오류 페이지는 안전한 오류 안내로 처리합니다.
- 액션·초안·발송함·규칙·작업·알림·MCP·추적 화면 등에서 잘못된 응답 때문에 전체 Workspace가 중단되지 않도록 처리하고, 페이지 오류 경계와 재시도 UI를 추가했습니다.

## 수신 메일 링크 열기

- 수신 HTML 메일의 `http`, `https`, `mailto` 링크를 검증하고 새 탭/창에서 열도록 정규화했습니다. 본문 iframe과 서버 CSP 양쪽에서 사용자 클릭으로 열린 링크가 동작하도록 수정했습니다.
- 스크립트 실행·폼 제출·부모 화면 이동은 계속 차단합니다. 링크의 opener·referrer 보호를 유지하고 위험한 URL scheme, 상대 경로, 임의 target·ping·download 속성은 허용하지 않습니다.
- 외부 이미지 기본 차단과 관리자 정책은 그대로 유지합니다.

## 인증 및 개인정보 보호

- 세션 확인 요청의 401 응답이 다시 세션 조회를 유발하는 반복을 방지했습니다.
- 만료·로그아웃·사용자 전환 시 이전 사용자의 캐시와 화면 상태가 남지 않도록 세션 복구를 보강했습니다.
- 잘못된 API 응답의 원문을 사용자 오류 안내에 노출하지 않습니다.

## 의존성 보안 업데이트

- 간접 의존성 `google.golang.org/grpc`를 `v1.82.1`에서 `v1.83.1`로 업데이트하여 HTTP/2 DATA 프레임 분할을 통한 메모리 고갈 취약점 [GO-2026-6348](https://pkg.go.dev/vuln/GO-2026-6348)을 해결했습니다. 다른 의존성 버전은 변경하지 않았습니다.

## 검증

- Go vet, 전체 Go race 테스트, REST/MCP 목록 계약 및 canonical API schema drift 검사
- React TypeScript 검사와 단위·회귀 테스트
- 실제 Chromium 기반 로그인·OIDC·메일·발송 흐름과 빈 액션 센터·메일 링크 회귀 테스트
- Go 실행 파일에 포함되는 React 정적 파일 재빌드
- Go 취약점·정적 보안 검사 및 프런트엔드 운영 의존성 취약점 검사

테스트는 로컬 테스트 데이터와 mock 메일/AI/OIDC 서비스를 사용하며 운영 메일 발송이나 운영 데이터 변경을 수행하지 않습니다.

## 업그레이드

v0.20.0에서 이 패치로 올릴 때 추가 DB 마이그레이션이나 설정 변경은 없습니다. 기존 데이터 볼륨·SecretStore·ObjectStore·KEK를 유지하고 백업 후 실행 파일 또는 컨테이너 이미지를 교체하세요. 웹 화면이 이전 자원을 캐시하고 있다면 새로고침하세요.

v0.19.x 이하에서 올리는 경우 [v0.20.0 이전 안내](v0.20.0.md)의 UI·Keycloak 콜백·MCP 권한·데이터 백업 주의사항을 먼저 확인하세요. 폐쇄망용 Go 단일 실행 파일과 이미지 배포를 유지하며 운영 시 Node 서버나 외부 CDN은 필요하지 않습니다.
